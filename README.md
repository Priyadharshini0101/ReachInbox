# ReachInbox

## Overview

A React application built with JavaScript, designed to help users manage and respond to emails efficiently. This project focuses on enhancing email productivity through a user-friendly interface.

## Installation

To install and run this project on your local machine, follow these steps:

1. **Clone Repository:**
   ```bash
   git clone https://github.com/Priyadharshini0101/ReachInbox.git

   cd reach-indox

   run `npm install`

   run `npm run dev`

   now open in browser 
   http://localhost:5173/
